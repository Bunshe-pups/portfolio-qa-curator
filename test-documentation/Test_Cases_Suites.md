## Детальные тест-кейсы (TC)

### TS-01: Smoke-тесты

**TC-1.1: Загрузка главной страницы (Позитивный)**
- **Предусловия:** Сайт развернут, кэш очищен.
- **Шаги:** 1. Ввести URL. 2. Дождаться полной загрузки DOM.
- **Ожидаемый результат:** Страница отображается без ошибок ≤ 2 сек.

**TC-1.2: Доступность раздела «Обратная связь» (Позитивный)**
- **Предусловия:** Главная страница загружена.
- **Шаги:** Кликнуть пункт меню «Обратная связь».
- **Ожидаемый результат:** Открывается корректная форма с полями ввода.

**TC-1.3: Базовая работоспособность поиска (Позитивный)**
- **Предусловия:** Главная страница загружена.
- **Шаги:** 1. Ввести текст в поиск. 2. Нажать «Найти».
- **Ожидаемый результат:** Переход на страницу результатов без ошибок сервера.

### TS-03: Ввод данных (Формы)

**TC-3.1: Форма обратной связи (Позитивный)**
- **Предусловия:** Открыта страница «Обратная связь».
- **Шаги:** 1. Заполнить имя, валидный email, текст. 2. Нажать «Отправить».
- **Ожидаемый результат:** Уведомление «Сообщение успешно отправлено», ответ ≤ 3 сек.

**TC-3.2: Подписка на рассылку (Негативный)**
- **Предусловия:** Email уже существует в базе подписчиков.
- **Шаги:** 1. Ввести тот же email повторно. 2. Нажать «Подписаться».
- **Ожидаемый результат:** Сообщение «Вы уже подписаны». Дубликат в БД не создан.
