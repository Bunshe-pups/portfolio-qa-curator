# Методы тест-дизайна (ЛР №4)

Анализ эквивалентных классов для оптимизации набора тестов веб-ресурса «Пантеон Дизайнера».

## Поле: Email (Форма обратной связи)

| № класса | Тип класса | Диапазон значений | Пример значения |
| :--- | :--- | :--- | :--- |
| 1 | Валидный | Корректный формат с «@» | Pantheon.dzn@gmail.com |
| 2 | Невалидный (формат) | Отсутствие «@» | Pantheon.dzn.gmail.com |
| 3 | Невалидный (пустое) | Обязательное поле | «» (пусто) |

## Поле: Поиск по ключевым словам

| № класса | Тип класса | Диапазон значений | Пример значения |
| :--- | :--- | :--- | :--- |
| 1 | Валидный | Корректное ключевое слово | Портфолио |
| 2 | Невалидный | Грамматические ошибки / спецсимволы | пырсптспв |

## Поле: Логин (Админ-панель)

| № класса | Тип класса | Диапазон значений | Пример значения |
| :--- | :--- | :--- | :--- |
| 1 | Валидный | Точное совпадение | admin |
| 2 | Невалидный | Опечатка / неверный ввод | admun |

## Эффективность применения методов

| Поле формы | Теоретическое кол-во комбинаций | Выделено классов | Фактическое кол-во тестов |
| :--- | :--- | :--- | :--- |
| Email | Бесконечное множество строк | 3 | 2 |
| Поиск | Все возможные слова и символы | 2 | 2 |
| Логин | Любые строки и пробелы | 2 | 2 |
| **Итого** | **Тысячи потенциальных проверок** | **7** | **6** |

> **Вывод:** Применение анализа эквивалентных классов позволило сократить количество необходимых проверок до минимально достаточного набора при сохранении полного покрытия требований к валидации входных данных.
