# Баг-репорт BPD-001

| Атрибут | Значение |
| :--- | :--- |
| **ID дефекта** | BPD-001 |
| **Краткое описание** | При повторной подписке с существующим email отображается общая ошибка вместо информативного сообщения |
| **Серьёзность (Severity)** | Major — функционал работает, но пользователь не получает понятной обратной связи, что снижает UX |
| **Приоритет (Priority)** | Medium — исправление желательно до релиза, но не блокирует основную функциональность |
| **Компонент** | Форма подписки на рассылку (footer) |
| **Окружение** | Chrome 124, Windows 11 |
| **Дата обнаружения** | 16.05.2026 |
| **Статус** | Open (назначен разработчику) |

## Шаги к воспроизведению
1. Открыть главную страницу сайта.
2. Пролистать до футера, найти форму подписки.
3. Ввести email, уже существующий в базе (например, `test@pantheon.dzn`).
4. Нажать кнопку «Подписаться».
5. Наблюдать отображаемое сообщение.

## Фактический результат
Появляется красное уведомление: *«Произошла ошибка. Попробуйте позже.»*

## Ожидаемый результат
Должно отображаться информативное сообщение: *«Вы уже подписаны на рассылку.»*
